# 2.1 Module Introduction

## Module Overview: LangChain for AI Agents

## Lesson 1: LangChain Basics and Core Components

- **Focus:** An introduction to fundamental LangChain concepts.

- **Key Components Covered:**

  - Models

  - Prompts

## Lesson 2: Building a Simple Agent Using LangChain

- **Focus:** Practical construction of a simple AI agent using the LangChain framework.

- **Key Concepts:**

  - **Tools:** Re-examining how tools function within an agent.

  - **The ReAct Pattern:** Revisiting this core design pattern to ensure critical concepts are fully internalized.

- *Note:* This lesson covers concepts touched on in Module 1; it can be skipped if the material feels familiar.

- **Focus:** A step-by-step internal walkthrough of the execution process that occurs when calling `agent.invoke`.

- **Example Used:** Reuses the simple math question example requiring multiple tool calls from Module 1 to maintain learning continuity across modules.
