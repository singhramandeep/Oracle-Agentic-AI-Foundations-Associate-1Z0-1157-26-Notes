# 3.1 Module Introduction

## Introduction to Model Context Protocol (MCP)

## 1. Core Definition

- **Acronym:** Model Context Protocol (MCP).

- **Origin:** An open standard introduced by **Anthropic in November 2024**.

- **Purpose:** Standardizes how AI models connect to external tools and data sources.

- **Module Goal:** Understand MCP conceptually and identify exactly where it fits within real-world systems.

## 2. Module Roadmap (4 Lessons)

## Lesson 1: Foundation

- Focuses on what MCP is and why it exists.

## Lesson 2: Core Mechanics

- Breaks down how the protocol actually works.

- Covers core components: **Hosts**, **Clients**, **Servers**, and **Primitives**.

## Lesson 3: Architectural Impact (Practice)

- **Continuity Example:** Revisits the simple multi-step math agent from Modules 1 and 2.

- **Implementation:** Creates a new MCP math server.

- **Comparison:** Evaluates "before MCP" versus "after MCP" architectures to demonstrate practical code and structural changes.

## Lesson 4: Real-World Application

- **Learning vs. Production:** Local/learning MCP servers differ from real-world usage.

- **Production Shift:** In production, servers are typically published by third parties; developers primarily write the client.

- **Code Impact:** Analyzes what changes in your client code—and what stays the same—when transitioning to published production servers.
