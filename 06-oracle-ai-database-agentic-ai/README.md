## Key Concepts Introduced

- **Oracle AI Vector Search** — Native vector storage and similarity search inside Oracle AI Database, combined with relational SQL. ([6.2](02-introduction-to-oracle-ai-vector-search.md))
- **VECTOR data type** — Oracle's native column type for storing embeddings alongside business data. ([6.3](03-oracle-ai-vector-search-workflow.md))
- **Embeddings** — Numeric vector representations of text, images or documents used for semantic similarity. ([6.3](03-oracle-ai-vector-search-workflow.md))
- **Vector Indexes (HNSW / IVF)** — Approximate indexes that make similarity search fast without full table scans. ([6.3](03-oracle-ai-vector-search-workflow.md))
- **VECTOR_DISTANCE** — SQL function that scores similarity between vectors (cosine, Euclidean, dot product, etc.). ([6.3](03-oracle-ai-vector-search-workflow.md))
- **RAG** — Retrieval-Augmented Generation: retrieve relevant chunks and pass them to the LLM as grounding context. ([6.3](03-oracle-ai-vector-search-workflow.md))
- **Private Agent Factory** — Oracle's no-code platform to build, govern and deploy enterprise agents anchored to approved data. ([6.5](05-oracle-ai-database-private-agent-factory.md))
- **Select AI** — Oracle Autonomous Database's natural-language-to-SQL capability, driven by AI Profiles. ([6.7](07-oracle-autonomous-ai-database-mcp-server.md))
- **ADB MCP Server** — A built-in, fully managed MCP server inside Autonomous AI Database; the database itself is the security boundary. ([6.7](07-oracle-autonomous-ai-database-mcp-server.md))
